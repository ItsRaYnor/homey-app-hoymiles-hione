    The IP address of the DTS-G3 stick on your network. Saved here, it is prefilled when pairing.
  

  
  
  
  
  
For the DTS-G3 use Modbus TCP on port 502. Try unit ID 1 first — that works on a DTS-WL-G3 out of the box. Only if there is no answer, see the note below.

  
  


  

    No Modbus answer? A DTS-WL-G3 normally answers on unit ID 1 without
    any configuration. If yours stays silent, it may be in Export Management mode: open the
    S-Miles Installer app → Me → Local Install Assistant / Toolkit → DTU Information →
    RS485 Port Config → choose Remote Control (NOT Export Control — that
    blocks Modbus), and use the Modbus/RS485 address set there (101–254).
